Conecta tu aplicación a DLLM

DLLM habla el protocolo de OpenAI en /v1: sirve para AnythingLLM, Open WebUI, Continue, LangChain, el SDK de OpenAI… El campo model elige el modelo; las herramientas (tools) llegan intactas al modelo.

Cómo configurarlo

Copia de seguridad

Un solo fichero con toda la configuración: secreto del clúster (los nodos vuelven a conectar solos), API key, parámetros de cada modelo, ajustes de nodos, nodos añadidos por IP, token de Hugging Face y la lista de modelos instalados (los modelos en sí no se incluyen: pesan demasiado; se pueden volver a descargar).

💾 Crear copia

Guárdala fuera de este equipo (otro disco, NAS, gestor de contraseñas). Sin la contraseña no se puede abrir.

♻️ Restaurar copia

Recuperación ante desastres

1. En el equipo nuevo, instala DLLM con el Instalador y elige Restaurar desde una copia (o, con DLLM ya instalado, usa «Restaurar copia» aquí o dllm backup import).
2. Los nodos siguen funcionando: la copia lleva el secreto del clúster, así que se reconectan solos (si no estaban en la misma red, quedan listados porque se recuerdan los añadidos por IP).
3. Descarga de nuevo los modelos que falten (botón en el resultado de la restauración).
